Arrays

Arrays are iterable, along with strings, Maps and Sets.

// Works with for...of loops:
for (const item of [1, 2, 3]) { console.log(item) }

split() Immutable

Splits a string into an array of substrings.

"hello".split('') // ['h', 'e', 'l', 'l', 'o']

Array.from() Immutable

Creates array from string or iterable.

Array.from("abc") // ['a', 'b', 'c']
